## Hierarquia e manutenção

Instruções atuais dos responsáveis e decisões posteriores explicitamente aprovadas prevalecem sobre textos antigos. Os documentos atuais consolidam essas decisões; o pacote histórico preserva a origem sem transformá-la em instrução ativa.

Uma sugestão só passa a decisão quando aprovada. Uma decisão só passa a implementação quando há evidência no projeto. Um teste só passa a realizado após execução e registro do resultado.

Registrar novas decisões com data conhecida, motivo, impacto, texto substituído e estado. Não inventar datas ausentes. Atualizar o documento do assunto e o histórico na mesma tarefa.
