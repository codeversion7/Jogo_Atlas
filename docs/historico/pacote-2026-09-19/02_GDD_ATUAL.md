# ATLAS — GAME DESIGN DOCUMENT ATUAL

# 1. VISÃO

ATLAS busca combinar:

- exploração;
- sobrevivência;
- descoberta;
- progressão narrativa;
- conquistas;
- coleta de fragmentos;
- mistério.

O prólogo funciona como uma unidade narrativa que apresenta o mundo e estabelece o conflito maior.

---

# 2. LOOP PRINCIPAL

O loop atual é:

1. explorar;
2. administrar recursos;
3. descobrir situações e oportunidades;
4. cumprir conquistas;
5. obter fragmentos;
6. completar gradualmente o livro;
7. compreender melhor a situação;
8. reunir todos os fragmentos;
9. provocar o evento final;
10. concluir o prólogo.

---

# 3. EXPLORAÇÃO

A exploração deve possuir propósito.

O jogador precisa ter motivos para investigar o ambiente.

Conquistas e fragmentos funcionam como parte dessa estrutura de incentivo.

---

# 4. CONQUISTAS

As conquistas possuem função narrativa.

Elas não existem somente para pontuação.

A realização de determinadas conquistas está ligada à obtenção dos fragmentos do livro.

A lista definitiva de conquistas ainda não foi estabelecida.

---

# 5. FRAGMENTOS

Os fragmentos são parte da progressão principal.

O sistema precisa futuramente conseguir:

- registrar quais fragmentos foram obtidos;
- impedir duplicações indevidas;
- verificar quando o conjunto está completo;
- iniciar o evento final.

---

# 6. COMIDA

A comida deve ser relativamente escassa.

Objetivos de design:

- incentivar planejamento;
- aumentar o valor da exploração;
- criar pressão;
- impedir que o recurso se torne irrelevante.

Não fixar números finais antes do balanceamento.

---

# 7. EVENTO FINAL

Condição:

**todos os fragmentos obtidos.**

Resultado:

**colapso/desabamento → fim do prólogo.**

---

# 8. MVP

## Essencial

- personagem;
- movimentação;
- interação;
- exploração;
- comida;
- conquistas;
- fragmentos;
- progressão;
- evento de encerramento.

## Não essencial inicialmente

- sistemas complexos;
- multiplayer completo;
- sistemas avançados de combate;
- grande quantidade de conteúdo;
- polimento avançado;
- cinematografia complexa.

A prioridade deve ser validar o ciclo.

---

# 9. PRINCÍPIO DE ESCOPO

O MVP deve responder:

> O núcleo de ATLAS é divertido e funcional?

Não deve tentar responder:

> Como será todo o jogo final?
