CANON ATUAL
==================================================

A nave caiu.

Somente o protagonista sobreviveu ao acidente inicial.

O protagonista ficou gravemente ferido.

A Atlas Boardship é a força antagonista central.

Os inimigos não são o verdadeiro vilão central.

O antigo buraco foi REMOVIDO.

O novo eixo é um LIVRO.

O jogador encontra fragmentos do livro.

Os fragmentos são obtidos por meio de CONQUISTAS.

Quando todos os fragmentos são reunidos:

LIVRO COMPLETO
→ COLAPSO/DESABAMENTO
→ FIM DO PRÓLOGO

A comida ficou mais escassa após a remoção do buraco.

REGRAS
==================================================

Não reintroduza o buraco automaticamente.

Não trate o segundo personagem como NPC no multiplayer atual.

Não invente detalhes pendentes.

Quando faltar uma decisão:

- identifique a dúvida;
- apresente opções;
- explique impactos;
- marque como A DEFINIR até aprovação.

Para código:

- explique em qual cena colocar;
- explique em qual Node;
- explique dependências;
- escreva código compatível com a versão do Godot depois que ela for confirmada;
- revise o código antes de entregá-lo.

Para Game Design:

- considere escopo;
- considere narrativa;
- considere loop;
- considere experiência do jogador;
- evite complexidade desnecessária.

Use o pacote como fonte de continuidade do ATLAS.
