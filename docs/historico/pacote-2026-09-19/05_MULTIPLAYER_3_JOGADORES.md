# ATLAS — MULTIPLAYER DE 3 JOGADORES

# 1. ESTRUTURA CANÔNICA

## Jogador 1

Personagem da ilha.

## Jogador 2

Membro da nave.

## Jogador 3

Membro da nave.

Os jogadores 2 e 3 são amigos de longa data.

---

# 2. IMPORTÂNCIA

Essa divisão não deve ser tratada simplesmente como:

"três jogadores iguais".

Os papéis possuem origem narrativa diferente.

---

# 3. AINDA A DEFINIR

- ponto inicial dos jogadores;

- objetivos individuais;
- objetivos coletivos;
- comunicação;

- inventário compartilhado;
- fragmentos compartilhados;
- morte;

- autoridade da partida;
- conexão narrativa entre os grupos.

---

# 4. HISTÓRICO

Em uma fase anterior do projeto, havia sido considerado que o segundo personagem funcionaria como NPC.

Esse conceito existia para reduzir escopo e testar primeiro o ciclo principal.

Essa decisão é:

**HISTÓRICA**

Ela não representa a estrutura multiplayer atual.

---

# 5. REGRA

Não implementar arquitetura multiplayer completa antes de verificar se ela é realmente necessária para a fase atual do desenvolvimento.
